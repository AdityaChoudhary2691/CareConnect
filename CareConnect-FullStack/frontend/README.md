# CareConnect Angular Frontend

Angular 20 frontend for the CareConnect EHR application.

## Run

Requirements: Node.js 20+.

```bash
npm install
npm start
```

The frontend runs at `http://localhost:4200` and calls the Spring Boot API at `http://localhost:8082/api`.

Start the backend and PostgreSQL first. See the project-root `README.md` for full setup instructions.
